# Йога-студия «Вдох»

Демо-сайт для портфолио. Студия вымышленная.

Идея: страница дышит. За всем текстом одно живое солнце, которое расширяется и сжимается в ритме 4-2-6 и медленно идёт по небу при прокрутке. Ночью оно становится луной со звёздами. Всё здесь движется медленно.

## Запуск

Сборка не нужна, это обычные статические файлы. Модули не откроются напрямую с диска, поэтому нужен любой локальный сервер, например `npx serve .`

## Устройство

| Файл | Что делает |
| --- | --- |
| `js/sky.js` | Солнце, луна и небо: небольшой шейдер на WebGL2. Без него остаётся обычный градиент |
| `js/pacer.js` | Счётчик дыхания 4-2-6 |
| `js/schedule.js` | Расписание недели и запись. Настоящее расписание клиента меняется здесь |
| `js/passes.js` | Абонементы и подбор самого выгодного |
| `js/main.js` | Путь солнца, «Подышать минуту», волны у направлений, анимации при прокрутке |

Форма в демо только показывает подтверждение. На сайте клиента запись подключается в `js/schedule.js`, в обработчике `submit`. Свободные места в демо тоже условные, настоящие приходят из системы записи студии.
